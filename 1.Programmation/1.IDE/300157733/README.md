# Documentation – Git et GitHub

1. J’ai accédé au dépôt GitHub du cours INF1084.
2. J’ai récupéré l’URL du dépôt GitHub.
3. J’ai cloné le dépôt sur mon ordinateur.
4. J’ai vérifié l’emplacement du dépôt local.
5. J’ai accédé au répertoire `1.Programmation/1.IDE`.
6. J’ai créé mon répertoire avec mon identifiant Boréal.
7. J’ai créé le fichier `README.md`.
8. J’ai ajouté mon répertoire avec la commande `git add`.
9. J’ai vérifié l’état du dépôt avec `git status`.
10. J’ai configuré mon nom et mon courriel Git.
11. J’ai configuré l’éditeur Git avec Nano.
12. J’ai créé un premier commit avec un commentaire.
13. J’ai utilisé `git pull` pour mettre à jour le dépôt local.
14. J’ai généré une clé SSH avec `ssh-keygen`.
15. J’ai renommé les fichiers de ma clé SSH.
16. J’ai configuré le fichier SSH `config`.
17. J’ai ajouté ma clé publique à mon compte GitHub.
18. J’ai configuré l’URL SSH du dépôt distant.
19. J’ai vérifié la configuration avec `git remote --verbose`.
20. J’ai préparé le dépôt pour envoyer mon travail avec `git push`.
