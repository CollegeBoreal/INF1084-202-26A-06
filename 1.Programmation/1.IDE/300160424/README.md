Configuration Git & SSH – Résumé en 5 étapes essentielles
1️⃣ Cloner le dépôt du cours
Créer le dossier de travail, puis cloner le dépôt GitHub du cours pour récupérer les fichiers nécessaires.

2️⃣ Créer mon dossier personnel
Dans le répertoire de la leçon, créer un dossier à mon nom (ID Boréal) et y ajouter un fichier README.md pour confirmer ma présence et mon travail.

3️⃣ Configurer Git
Définir mon nom, mon email Boréal et l’éditeur par défaut.
Faire mon premier commit pour enregistrer mes modifications localement.

4️⃣ Créer et installer ma clé SSH
Générer une clé SSH, la renommer, créer le fichier de configuration SSH, puis ajouter ma clé publique dans mon compte GitHub pour activer l’accès sécurisé.

5️⃣ Passer le dépôt en mode SSH et envoyer mon travail
Changer l’URL du dépôt pour utiliser SSH, vérifier la configuration, puis envoyer mes fichiers sur GitHub avec git push.
