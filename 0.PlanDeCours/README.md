## :b: Plan de Cours 📈 

### 🚀 INF1084 – Administration Windows (Automne 2026)

### 📚 Aperçu du cours

```
Cours : Automne-2026-INF-1084-202-06-Administration-Windows.pdf
 Programme : Techniques des systèmes informatiques (TSIQ)
 Durée : 56 heures
 Préalable : INF1092-200 ou INF1092-201
```

### 🎯 Description

Ce cours permet aux étudiants de maîtriser l'administration avancée de Windows Server dans un environnement d'entreprise. Les principaux thèmes couverts sont :

- 🏢 Active Directory et les domaines
- 👥 Gestion des utilisateurs et groupes
- 🔐 Permissions et sécurité
- ⚙️ Automatisation administrative
- 📜 Documentation technique
- 🛡️ Stratégies de groupe (GPO) et sécurité Windows

### 🌟 RAC 1 – Installation et configuration d'un domaine

#### 📖 Connaissances
- Comprendre le rôle d'Active Directory
- Identifier les objets AD (utilisateurs, groupes, ordinateurs)
- Comprendre les forêts, arbres et domaines
- Comprendre les trusts et les rôles FSMO

#### 🛠️ Compétences pratiques
- Installer Active Directory
- Configurer des domaines et forêts
- Créer un environnement multidomaine
- Configurer des sites et la réplication
- Gérer les rôles FSMO
- Documenter l'environnement AD

#### ✅ Objectif : Déployer une infrastructure Active Directory professionnelle.

### 👥 RAC 2 – Gestion administrative des comptes

#### 📖 Connaissances
- Types de permissions
- Organisation logique des comptes
- Gestion des groupes et OU

#### 🛠️ Compétences pratiques
- Créer et gérer :
    - 👤 Utilisateurs
    - 👥 Groupes
    - 💻 Ordinateurs
- Déléguer l'administration
- Structurer les OU
- Automatiser les tâches administratives
- Prioriser les demandes de soutien TI

#### ✅ Objectif : Administrer efficacement les ressources d'une organisation.

### 🔐 RAC 3 – Gestion avancée des groupes et utilisateurs

#### 📖 Connaissances
- Différences entre politiques utilisateurs et ordinateurs
- Comptes de services Windows

#### 🛠️ Compétences pratiques
- Configurer les stratégies de compte
- Déployer des politiques de mots de passe
- Gérer les comptes de services
- Configurer les GPO pour utilisateurs et ordinateurs
- Produire la documentation technique

#### ✅ Objectif : Centraliser et sécuriser la gestion des comptes.

### ⚙️ RAC 4 – Stratégies de groupe (GPO)

#### 📖 Connaissances
- Architecture des GPO
- Traitement des politiques

#### 🛠️ Compétences pratiques
- Configurer les paramètres GPO
- Appliquer des paramètres de sécurité
- Utiliser les modèles administratifs
- Configurer les préférences GPO
- Utiliser :
    - 📊 Group Policy Results
    - 🔮 Group Policy Modelling
- Sauvegarder et restaurer des GPO

#### ✅ Objectif : Standardiser et sécuriser les postes Windows d'une entreprise.

## 💡 Compétences développées

À la fin du cours, l'étudiant pourra :

- ✅ Déployer un domaine Active Directory complet
- ✅ Gérer des forêts et domaines multiples
- ✅ Administrer les utilisateurs, groupes et OU
- ✅ Configurer les stratégies de groupe (GPO)
- ✅ Appliquer les bonnes pratiques de sécurité Microsoft
- ✅ Automatiser certaines tâches administratives
- ✅ Produire une documentation professionnelle
- ✅ Réaliser des tâches d'administration Windows Server en contexte réel
