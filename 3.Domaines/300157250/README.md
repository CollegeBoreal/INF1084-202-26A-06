Dans ce laboratoire, j’ai installé et configuré Active Directory (AD DS) sur Windows Server 2022. J’ai commencé par renommer le serveur, puis j’ai installé le rôle Active Directory Domain Services.

Ensuite, j’ai créé un nouveau domaine nommé DC.local et installé le service DNS, qui permet aux ordinateurs de trouver le contrôleur de domaine sur le réseau.

Après le redémarrage du serveur, j’ai vérifié que l’installation avait bien fonctionné avec différentes commandes PowerShell. J’ai aussi confirmé que le domaine, la forêt et le contrôleur de domaine étaient opérationnels.

Ce laboratoire m’a permis d’apprendre à créer un domaine Active Directory, à comprendre le rôle du contrôleur de domaine et à utiliser PowerShell pour installer et vérifier les services nécessaires au bon fonctionnement du réseau.
